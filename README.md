# 📈 تطبيق توصيات التداول

تطبيق ويب يعطي **توصيات تداول** (اتجاه + نقطة دخول + وقف خسارة + أهداف) للذهب،
الفوركس، الكريبتو والمؤشرات — بالاعتماد على **بيانات سوق حقيقية** ومؤشرات فنية،
ثم يُمرّرها إلى **Claude** لتوليد توصية مشروحة باللغة العربية.

## المميزات

- 🟢🔴 توصية واضحة لكل أداة: **شراء / بيع / محايد** مع نسبة قوة الإشارة.
- 🎯 مستويات جاهزة: دخول، وقف خسارة، وهدفين (محسوبة من ATR ومنقّحة بالذكاء).
- 📊 بيانات حقيقية مجانية من **Yahoo Finance** (بدون مفاتيح): الذهب، الفضة،
  أزواج فوركس رئيسية، بيتكوين/إيثيريوم/سولانا، وداو/ناسداك/S&P.
- 🤖 محرك مزدوج: يستخدم **Claude** إن توفّر مفتاح، وإلا يعمل تلقائياً
  بمحرك قواعد فنية شفّاف (RSI + المتوسطات + الزخم).
- 🌙 واجهة عربية (RTL) بتصميم داكن أنيق تعرض التوصيات مباشرة.

## البنية

```
app.py                  # خادم Flask + مسارات API
engine/
  symbols.py            # سجل الأدوات (اسم عربي ↔ رمز Yahoo)
  market_data.py        # جلب الشموع من Yahoo Finance
  indicators.py         # RSI / EMA / ATR / تصنيف الاتجاه (بدون مكتبات ثقيلة)
  recommender.py        # توليد التوصية عبر Claude + fallback بالقواعد
templates/index.html    # واجهة الويب العربية
tv_claude_bridge.py     # (اختياري) جسر TradingView → Claude → Telegram
```

## التشغيل

```bash
pip install -r requirements.txt

# اختياري لتفعيل توصيات Claude:
export ANTHROPIC_API_KEY=sk-ant-...
# export CLAUDE_MODEL=claude-opus-4-8   # الافتراضي

python app.py
```

ثم افتح: <http://localhost:5000>

بدون `ANTHROPIC_API_KEY` يعمل التطبيق مباشرة بمحرك القواعد، والواجهة توضّح
مصدر كل توصية (🤖 تحليل Claude أو ⚙️ تحليل بالقواعد).

## واجهة الـ API

| المسار | الوصف |
|--------|-------|
| `GET /` | لوحة التوصيات |
| `GET /api/instruments` | قائمة الأدوات والفئات |
| `GET /api/recommendation/<id>` | توصية مفصّلة لأداة (مثل `XAUUSD`, `BTCUSD`, `US30`) |
| `GET /api/health` | فحص الحالة |

نتائج التوصية مخزّنة مؤقتاً (120 ثانية) لتخفيف الضغط على المزوّد والنموذج.

## إضافة أداة جديدة

أضف سطراً في `engine/symbols.py` مع رمز Yahoo المناسب:

```python
{"id": "AAPL", "yahoo": "AAPL", "name_ar": "آبل", "name_en": "Apple",
 "category": "indices", "decimals": 2},
```
