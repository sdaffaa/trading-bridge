# بَصيرة كابيتال (Baseera Capital)

**بيت تحليل مالي وفني ذكي متخصص في بورصة الكويت** — يعمل بنظام فريق من الوكلاء
(Agents)، كل وكيل له مهمة محددة، يجتمعون تحت إدارة مدير الاستثمار لإصدار توصية
استثمارية واضحة (شراء / بيع / احتفاظ) مع سعر مستهدف ووقف خسارة وأفق زمني.

> ⚠️ **تنبيه:** هذا نظام تحليل آلي لأغراض تعليمية/بحثية وليس نصيحة استثمارية.
> البيانات النموذجية تمثيلية وتُستبدل ببيانات حيّة عبر `LiveProvider`.

---

## فريق الوكلاء ومهامهم

| # | الوكيل | المهمة المتخصصة |
|---|--------|-----------------|
| 1 | **وكيل بيانات السوق** | جمع بيانات السهم اللحظية، تقييم السيولة، والتحقق من جودة البيانات |
| 2 | **وكيل التحليل الفني** | قراءة المؤشرات الفنية (RSI, MACD, المتوسطات 20/50/200)، تحديد الاتجاه والدعوم/المقاومات وإصدار إشارة فنية |
| 3 | **وكيل التحليل المالي** | قراءة النِسب المالية (P/E, P/B, ROE, الهوامش, المديونية, التوزيعات, النمو) وتقييم القيمة والجودة |
| 4 | **وكيل الأخبار والمشاعر** | قراءة أخبار السهم/القطاع واستخلاص المشاعر السوقية وأثرها |
| 5 | **وكيل إدارة المخاطر** | قياس التقلب (ATR) والبيتا والمديونية والسيولة، واقتراح حجم مركز ووقف خسارة |
| 6 | **مدير الاستثمار (CIO)** | دمج آراء الفريق بأوزان وإصدار التوصية النهائية والمسوّغ |

كل وكيل يُصدر تقريراً موحّداً: **إشارة** (إيجابي/سلبي/محايد) + **درجة** من −100 إلى
+100 + **ثقة** + ملخص ونقاط ومخاطر. يوازن مدير الاستثمار الدرجات بالأوزان التالية:

```
التحليل المالي 32% | التحليل الفني 30% | إدارة المخاطر 15% | الأخبار 13% | بيانات السوق 10%
```

## طريقة العمل (وضعان)

1. **وضع الذكاء الاصطناعي:** عند ضبط `ANTHROPIC_API_KEY`، يستدعي كل وكيل نموذج
   Claude بشخصيته ومهمته للحصول على تحليل نصي غني، مستنداً إلى الأرقام المحسوبة.
2. **الوضع الاحتياطي الكمّي:** بدون مفتاح، يعمل النظام بالكامل بقواعد كمية صريحة
   (مؤشرات محسوبة فعلياً من سلسلة سعرية) — فلا يتوقف أبداً.

## التثبيت

```bash
pip install -r requirements.txt
cp .env.example .env   # ثم املأ المفاتيح (اختياري)
```

## الاستخدام — سطر الأوامر

```bash
python main.py agents              # عرض الوكلاء ومهامهم
python main.py list                # الأسهم المتاحة
python main.py analyze KFH         # تحليل سهم وإصدار توصية
python main.py analyze ZAIN --json # مخرجات JSON
python main.py analyze NBK --telegram   # إرسال الملخص عبر تيليجرام
```

الأسهم النموذجية المتاحة: `NBK, KFH, BOUBYAN, GBK, ZAIN, AGILITY, MABANEE,
HUMANSOFT, GFH, KPROJ`.

## الاستخدام — كخادم API

```bash
python tv_claude_bridge.py    # يشغّل Flask على المنفذ 5000
```

| المسار | الوصف |
|--------|-------|
| `GET /` | معلومات الشركة |
| `GET /health` | فحص الصحة |
| `GET /agents` | الوكلاء ومهامهم |
| `GET /symbols` | الأسهم المتاحة |
| `GET /analyze/<symbol>` | تحليل سهم (JSON) |
| `POST /analyze` | `{"symbol":"KFH","telegram":true}` |
| `POST /webhook` | (توافق قديم) استقبال تنبيه TradingView وتحليله |

مثال:

```bash
curl http://localhost:5000/analyze/KFH
```

## الاستخدام — كمكتبة Python

```python
from baseera import BaseeraCapital, format_report

firm = BaseeraCapital()
result = firm.analyze("KFH")
print(format_report(result))
print(result["recommendation"]["action"])   # شراء / بيع / احتفاظ
```

```
baseera/
├── data/
│   ├── models.py           نماذج البيانات (Quote, Financials, AgentReport ...)

│   ├── base.py             الفئة الأساسية (LLM + الوضع الاحتياطي)
│   ├── market_data_agent.py
│   ├── technical_agent.py
│   ├── fundamental_agent.py
│   ├── news_agent.py
```

## ربط البيانات الحيّة

عدّل `baseera/data/boursa_kuwait.py` → صنف `LiveProvider` وأعد تنفيذ دوال الجلب
(`get_quote`, `get_financials`, ...) بنفس التواقيع لربط واجهة بورصة الكويت أو أي
مزوّد خارجي — لن يحتاج بقية النظام لأي تعديل. ثم شغّل بـ `BASEERA_LIVE=1` أو
`python main.py --live analyze KFH`.
