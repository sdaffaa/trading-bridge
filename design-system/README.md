# Liquidity State — Design System

نظام التصميم الرسمي لحساب **@liquidity.state** التعليمي. هذا المجلد هو المصدر
الوحيد للحقيقة (single source of truth) لكل تصميم: ريلز، كاروسيل، بوستر، دليل
PDF، وشارت. أي قطعة محتوى يجب أن تُبنى من هذه الملفات حرفيًا.

> قاعدة عامة: لا نسخة مبسطة من أي عنصر (لا للوقو، ولا للشارت). كل شيء محسوب
> ومثبّت على قيم حقيقية.

---

## 1. البنية (Structure)

```
design-system/
├── css/
│   ├── tokens.css        # كل الألوان/الخطوط/الزوايا/الحركة (المصدر الوحيد)
│   ├── base.css          # التايبوغرافي، RTL، الأسطح، الأشكال، الشارات، الأسهم
│   ├── chart.css         # ستايل الشارت الصارم (وسوم بهالة، خطوط، صناديق)
│   └── chart.js          # محرك الشارت: يرسم من OHLC حقيقي ويثبّت الوسوم على السعر
├── fonts/
│   ├── tajawal.local.css # Tajawal مستضاف محليًا (عربي + لاتيني، 400–900)
│   └── *.woff2           # ملفات الخط (تعمل أوفلاين وبدون شبكة)
├── logo/
│   ├── generate_logo.py  # مولّد اللوقو العشريني هندسيًا (بالنسبة الذهبية)
│   ├── icosahedron.svg   # النسخة الفاتحة (للأسطح الكريمية)
│   └── icosahedron-dark.svg # نسخة الغلاف بتوهج سيان
└── templates/
    ├── cover-poster.html   # غلاف غامق 1080×1920 (أول مشهد فقط)
    ├── content-page.html   # صفحة محتوى كريمية 1080×1920 + شارت
    ├── carousel-slide.html # سلايد كاروسيل/دليل 1080×1350
    ├── mistake-01.html     # كاروسيل «أخطاء»: الخطأ 01 — تدخل قبل التأكيد
    └── mistake-02.html     # كاروسيل «أخطاء»: الخطأ 02 — تطارد الشمعة
```

قوالب سلسلة «أخطاء المتداولين» (1080×1350) تستخدم `css/series.css` + `css/series.js`
(محرك شارت يضيف الموصّلات والعلامات ✓/✗ والوسوم المهالة بلا إطارات). كل وسم/علامة
مثبّت على سعر شمعة حقيقي، والقواعد الصارمة محفوظة: وسوم بلا مربعات، زوايا 0–3px،
أرقام لاتينية مائلة، أسهم «اسحب ←» يسار، والسطح كريمي (التوهج للغلاف فقط).

كل تصميم يبدأ بربط `tokens.css` ثم `base.css` (ثم `chart.css` إذا فيه شارت).

## 2. الهوية والألوان

كل التوكنز معرّفة في `css/tokens.css`. ممنوع كتابة لون خام (hex) في أي تصميم —
استخدم المتغيّر.

| الاستخدام | التوكن | القيمة |
|---|---|---|
| خلفية المحتوى (radial) | `--ls-bg-content` | `#F7F3EC → #F2EEE7 → #ECE6DB` |
| العناوين/النص الأساسي (كحلي) | `--ls-ink` | `#0F2E3C` |
| النص الثانوي | `--ls-text-2` | `#5C6C73` |
| المحاور | `--ls-axis` | `#93A2A8` |
| تركواز أساسي / غامق / فاتح | `--ls-turq` / `--ls-turq-dark` / `--ls-turq-light` | `#2E7D96` / `#1E627A` / `#5AA6BC` |
| شمعة صاعدة / هابطة | `--ls-candle-up` / `--ls-candle-down` | `#2E8CA6` / `#122F3E` |
| الأحمر (هابط حصريًا) | `--ls-red` | `#D24B4B` |
| خلفية الغلاف (radial غامق) | `--ls-bg-cover` | `#0C2029 → #08131C → #04090F` |
| توهج سيان (الغلاف) | `--ls-cyan-glow` | `#43D4DC` |
| تدرّج العنوان المعدني | `--ls-title-metal` | `#fff → #C4D4DB → #7F97A1` |
| حواف اللوقو | `--ls-logo-edge` | `#54687A` |

**دلالة الألوان (إلزامية):** كحلي = مستويات محايدة · تركواز = صاعد/كسر صاعد ·
أحمر = هابط/انعكاس فقط (LL/LH/CHoCH/سحب سيولة). لا تستخدم الأحمر لأي شيء صاعد.

**الغلاف فقط** (أول مشهد/صفحة) يستعمل السطح الغامق + العنوان المعدني + فواصل
السيان المتوهجة بمعيّن + Wordmark فضي «LIQUIDITY STATE» بتباعد أحرف واسع. كل ما
بعده كريمي.

**الخط:** Tajawal فقط — Bold/ExtraBold/Black للعناوين، Medium/Regular للنص.
عربي RTL سليم التشكيل. الخط مستضاف محليًا في `fonts/` فما يعتمد على الشبكة.

## 3. اللوقو (Icosahedron)

مجسّم عشريني الأوجه محسوب هندسيًا في `logo/generate_logo.py`:

- 12 رأس على النسبة الذهبية φ، 20 وجه مثلثي (طوبولوجيا الإيكوساهدرون القياسية).
- توجيه «رأس للأعلى» والنظر عبر محور ثلاثي فيطلع السيلويت سداسيًا (rx≈54°).
- تظليل معدني فضي مدفوع باتجاه الضوء (رامب من `#6B7C87` إلى `#F3F7F9`)، حواف
  `#54687A`.
- نسخة الغلاف الغامقة تضيف توهج سيان.

توليد الملفات:

```bash
cd design-system/logo
python3 generate_logo.py         # -> icosahedron.svg
python3 generate_logo.py --dark  # -> icosahedron-dark.svg
```

> ممنوع أي نسخة مبسطة/فلات للّوقو. استخدم SVG المولّد فقط.

## 4. قواعد الشارتات (صرامة كاملة)

المحرك `css/chart.js` + ستايل `css/chart.css` يفرضان القواعد بالكود:

1. **عدد الشموع:** الشروحات التعليمية 20–40 شمعة (الافتراضي 30). المحرك يرفض أي
   شيء خارج هذا المدى (6–10 شموع ممنوعة).
2. **ممنوع تكرار أي شارت** — لا بين مشاهد الفيديو الواحد ولا بين فيديو وآخر. كل
   مشهد بيانات شموع جديدة كليًا بشكل وإيقاع مختلف فعليًا.
3. **مشهد «السوق الحقيقي»:** بيانات OHLC حقيقية فقط من مصدر موثوق. لا تخترع شموع.
   كل فيديو بنافذة زمنية أو أداة جديدة لم تُستخدم قبل.
4. **الماركب دقيق بلا عشوائية:** الدوال `hline / box / breakArrow / tag` تأخذ
   **سعرًا** وليس بكسل، فكل خط/صندوق/سهم ينطبق على فتيل أو إغلاق حقيقي بالضبط.
   BOS على رأس فتيل القمة، SSL على قاع الفتيل، حدود الصناديق على أسعار السوينق
   الفعلية، ورأس سهم الكسر يلامس الخط تمامًا.
5. **الوسوم بدون إطارات:** نص Tajawal + هالة بلون الخلفية الكريمية عبر
   `paint-order: stroke` بسماكة ~6px (كلاس `.ls-tag`). ممنوع أي مربع حول
   الكلمات على الشارت.
6. **الخطوط الأفقية:** رفيعة 1.6–1.8px بنهايات دوائر مقبض (ستايل TradingView).
7. **الصناديق (رينج/OB):** تعبئة تركواز 14–18% + حد 1px تركواز غامق. ممنوع الرمادي.
8. **الألوان:** كحلي = محايد، تركواز = صاعد/كسر صاعد، أحمر = هابط/انعكاس فقط.

مثال استخدام المحرك:

```js
import { LSChart } from "../css/chart.js";
const c = new LSChart(svgEl, realOHLC, { width: 880, height: 1120 });
c.render();
c.hline(2341, { tone: "bull", label: "BOS" });   // على سعر حقيقي
c.box(16, 19, 2342, 2323, { label: "OB" });        // على أسعار سوينق حقيقية
c.breakArrow(20, 2341, { tone: "bull" });          // الرأس يلامس الخط
c.tag(21, 2341, "كسر صاعد", { tone: "bull" });
```

## 5. الأشكال والأرقام

- كل المربعات والمستطيلات حادة رسمية: `border-radius` من 0 إلى 3px فقط
  (`--ls-radius-0..2`)، حدود رفيعة 1.5px.
- **شارات الخطوات** (`.ls-step`): مربع بزوايا صفر، أرقام لاتينية `1 2 3` مائلة
  (italic) وزن 900 — ممنوع `١ ٢ ٣` فيها.
- **العدادات** (`.ls-counter`، مثل `n/20`): أرقام لاتينية باتجاه LTR داخل سطر RTL.
- **الأسهم داخل الجمل العربية** تشير يسار «←» باتجاه القراءة (السبب ← النتيجة).
  ممنوع «→» (استخدم كلاس `.ls-arrow`).

## 6. المعجم (كويتي، إلزامي)

«حدد القمم والقيعان» (مو علّم) · «تغيّر نمط» (مو تغيّر طابع) · «خلّ الدرس معاك»
(مو خذ الدرس معك) · «يبين معاك الهيكل» (مو يبان لك) · بدون وعود أرباح · وسم
«لغرض تعليمي» (`.ls-edu-tag`) على أي محتوى فيه بيانات حقيقية · كل درس له كلمة
تعليق ManyChat عبر `.ls-keyword` (مثل: ستركجر، بلوك).

## 7. الفيديو (ريلز)

- 1080×1920 @ 30fps، المدة ~60 ثانية، 12 مشهد:
  بوستر غامق ← هوك ← تعريف ← تفصيل بالأرقام ← مثال حقيقي (الذروة: فلاش أبيض
  خفيف + زوم 6% عند لحظة الكسر) ← اقتباس ← CTA.
- الشموع تُبنى تتابعيًا (`scaleY` مع back-ease → `--ls-ease-back`)، الخطوط
  تُرسم بـ `stroke-dashoffset`، الوسوم تنبثق `scale 0→1`.
- انتقالات crossfade 0.45s (`--ls-crossfade`) + Ken Burns خفيف (1.008→1.028).
- الكاروسيل/الدليل: 1080×1350.

## 8. الجودة قبل التسليم

افحص إطارات/صفحات **فعلية** (رندر PNG وتأكد بصريًا):

- العربي متصل غير معكوس، سليم التشكيل.
- لا تداخل نصوص، الهوامش سليمة.
- الماركب منطبق على الفتائل بالضبط.
- كل شارت غير مكرر (شكل/إيقاع مختلف فعليًا).
- الغلاف وحده غامق؛ كل ما بعده كريمي.

رندر سريع عبر Chromium بلا شبكة:

```bash
CHROME=/opt/pw-browsers/chromium-1194/chrome-linux/chrome
"$CHROME" --headless --no-sandbox --allow-file-access-from-files \
  --window-size=1080,1920 --virtual-time-budget=4000 \
  --screenshot=out.png "file://$PWD/templates/content-page.html"
```

> ملاحظة القوالب: بيانات OHLC في `content-page.html` تجريبية للقالب فقط. أي مشهد
> «سوق حقيقي» يجب أن تُحقن فيه بيانات موثقة حقيقية.
