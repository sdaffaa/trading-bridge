# ريل — الاختبار الممول: حجم المخاطرة اهو اللي يعدّيك

**Pillar 3 (سيكولوجيا وإدارة رأس المال) · TOF+MOF · XAUUSD 15m · 21.0s · 1080×1920 @30fps**
CTA: ManyChat keyword → «ممول»

هذا الحزمة هي مخرجات `script-spec-bridge` للسكربت المدموج: تحويل السكربت (VO كويتي + بلوكات
سينمائية) إلى `script.spec.json` مُتحقَّق منه، ثم manifests الإنتاج.

## الملفات

| الملف | الوصف |
|---|---|
| `script.md` | السكربت المدموج — المصدر الوحيد للكتابة (11 بيت، 21.0s) |
| `script.spec.json` | مصدر الحقيقة المُتحقَّق منه + بلوك الـ audit |
| `vo_manifest.json` | 10 مقاطع صوتية (البيت 11 CARE صامت بالتصميم) |
| `build/remotion.props.json` | مشاهد بفريمات دقيقة + حركة كاميرا/نص + palette + safe zones |
| `build/sfx_cues.json` | 20 كيو صوتي موقّت للمكس (VO −14 LUFS · bed −18dB · duck 4dB) |
| `build/captions.srt` | كابشنات — لازم reshape عبر `arabic-video-text` قبل الحرق |

## إعادة توليد الحزمة

```bash
SK=~/.claude/skills/script-spec-bridge/scripts
python3 "$SK/parse_script.py"    script.md -o script.spec.json
python3 "$SK/validate_spec.py"   script.spec.json --write        # البوابة — exit 1 = لا تنتج
python3 "$SK/spec_to_vo.py"      script.spec.json -o vo_manifest.json --engine elevenlabs --rate 1.1
python3 "$SK/spec_to_render.py"  script.spec.json -d build
```

## ملاحظات لخطوة الـ VO (تسليم لـ `arabic-voiceover` / ElevenLabs)

كل مقطع لازم يدخل داخل `budget_s` بدون تجاوز 1.15×. المقاطع الضيّقة:

- **البيت 9 (VERDICT · الذروة · 0.7s):** الـ VO «عشان جذي دفعت فلوسه بالاختبار… وطحت»
  يركب عبر الـ hard cut داخل headroom البيت 10 (PROOF · 2.7s فيه كلمتين فقط «شوف الأرقام»).
  مجموع 0.7+2.7 = 3.4s لـ 8 كلمات ≈ 2.4 كلمة/ث — مريح. لا تقفل الـ VO على حد البيت.
- **البيتات 5+6 و7 و8 و12 (≈4.3–5.0 كلمة/ث):** إلقاء كويتي سريع يمشي؛ إذا الرندر أطول من
  الميزانية، قصّر السطر — لا تسرّع الصوت فوق 1.15×.
- الصوت: `elevenlabs` صوت البراند بمعدل 1.1× (حسب القسم 6 — بانتظار التأكيد النهائي أدناه).

## انحرافات مقصودة عن المستند الأصلي (للشفافية)

1. **VO البيت 9 (VERDICT):** المستند الأصلي كتبه «عشان جذي تدفع فلوس الاختبار… وتطيح».
   تم محاذاته إلى «عشان جذي دفعت فلوسه … وطحت» ليعيد صياغة الهوك حرفياً (دفعت/فلوسه/وطحت)
   — وهذا هو هدف الدائرية المُعلن بالمستند نفسه («إعادة صياغة حرفية للبيت 1»). بدون هذه
   المحاذاة يفشل البند 14 آلياً (تطابق كلمات حرفي)، فيصير السكور 14/15 بدل 15/15.
2. **البيت 11 (CARE):** صامت بالتصميم (صمت مقصود قبل الـ CTA) — بدون سطر VO، فلا يُنتَج له مقطع.
3. **ترقيم البيتات:** المستند دمج 7A/7B؛ هنا صارت البيت 7 والبيت 8 (كلاهما TURN) ليتوافق
   مع صيغة الـ parser، والـ VERDICT صار البيت 9. التوقيتات مطابقة للمستند (المنحنى:
   2.6·1.6·0.8·1.2·2.4·2.0·2.6·0.7·2.7·1.4·3.0).
