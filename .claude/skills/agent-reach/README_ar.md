# agent-reach — حالة التركيب في هذه البيئة

**المصدر:** [Panniantong/Agent-Reach](https://github.com/Panniantong/Agent-Reach) ·
مُركَّب بـ`npx skills add Panniantong/Agent-Reach@agent-reach` ومقيَّد في
`skills-lock.json` (‏`agent_reach/skill/SKILL.md`).

**ما هو:** موجِّه وصولٍ للإنترنت — يعطي الوكيل قراءةً وبحثاً على خمس عشرة
منصّة (تويتر · ردّيت · يوتيوب · جيت‑هَب · بيليبيلي · شياو‑هونغ‑شو ·
إنستغرام · فيسبوك · لينكدإن · V2EX · شيويتشيو · RSS · صفحات ويب · بحث ويب)
عبر خلفيّاتٍ متعدّدة مع تحويلٍ تلقائي عند سقوط إحداها.

**التشغيل التلقائي:** السكل يُستدعى من `description` وحده — أي طلب بحث أو
رابط منصّة يوقظه بلا أمرٍ منك. لا يحتاج روتيناً مجدولاً كي «يعمل»؛
الروتين يُضاف فقط إن أردتَ مهمّةً دوريّة تستعمله.

## 🔒 قياس الشبكة في هذه الحاوية — 2026-08-11

بوابة خروج الحاوية تحجب **كل قنوات المحتوى** التي يقوم عليها السكل. قيس
بـ`curl` على الحاوية نفسها لا بتقدير:

|---|---|

| `x.com` · `twitter.com` | ⛔ لا اتصال |
| `www.reddit.com` · `www.youtube.com` · `www.bilibili.com` | ⛔ لا اتصال |

وحزمة بايثون الرسميّة **لا تُركَّب هنا**: مسار التركيب الوحيد الذي يوصّفه
المشروع هو أرشيف GitHub، وهو محجوب (403). و`pip install agent-reach` من
PyPI يجلب **مشروعاً آخر** يحمل الاسم نفسه (v0.1.0 لـ Jean Galea، أوامره
`list/install/remove/doctor/get/skill/cache`) — رُكّب للفحص ثم أُزيل، وهو
ليس هذا السكل. لا تُركّبه: السكل ينادي `agent-reach doctor --json` فيجيبه
غريبٌ بجوابٍ فارغ `[]` ويبدو كأن القنوات ميتة لا محجوبة.

كذلك ينقص من الأدوات التي يوجّه إليها السكل: `gh` · `mcporter` · `opencli`
· `twitter` · `rdt` · `bili` · `feedparser`. الموجود `yt-dlp` وحده،
وقناته (يوتيوب) محجوبة.

## ماذا يلزم كي يعمل

**سياسة شبكة الحاوية** — تُضبط عند إنشاء بيئة Claude Code على الويب، لا من
داخل الجلسة: <https://code.claude.com/docs/en/claude-code-on-the-web>.
افتح المضيفات المطلوبة (أو استعمل سياسةً أوسع)، ثم:

```bash
pipx install https://github.com/Panniantong/agent-reach/archive/main.zip
agent-reach install --env=auto
agent-reach doctor --json      # المرجع لما يعمل فعلاً
```

ولأن الحاوية **زائلة** — تُبنى من جديد مع كل تشغيلة مجدولة — فالحزمة
والإعدادات في `~/.agent-reach/` لا تبقى. أي روتين يستعمل السكل عليه أن
يبدأ بسطر التركيب أعلاه، أو يُنقل التركيب إلى سكربت إقلاع البيئة.

## قنوات لا تمرّ من البوابة أصلاً

المنصّات التي يحتاج السكل فيها جلسة دخول (تويتر · ردّيت · شياو‑هونغ‑شو ·
فيسبوك · إنستغرام) تحتاج كوكيز المستخدم. وهذي **لا تُوضع في المستودع ولا
تُمرَّر داخل صندوق `sandbox_exec`** — القاعدة نفسها التي تحكم مفاتيح
ElevenLabs وTwelve Data: ملف `.env` غير متعقَّب وحده.
