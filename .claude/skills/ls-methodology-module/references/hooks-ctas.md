# Approved hooks & keyword CTAs (per primary school)

Use a hook only if the real chart actually shows it. Hook style = a short counter-expectation line + a short
question (see liquidity-state-brand / fahad-script-voice for the exact voice).

| School | Hook options | CTA keyword |
|---|---|---|
| SMC | «الكسر هذا مو تغيير اتجاه.» / «شنو اللي ناقص؟» | `هيكل` |
| ICT | «السيولة انأخذت… والدخول بعده.» / «وين التأكيد؟» | `سيولة` |
| Footprint | «السعر صعد… والدلتا ما صدّقت.» / «منو المحبوس؟» | `دلتا` |
| Volume Profile | «السعر خرج… بس ما انقبل.» / «وين يرجع؟» | `بروفايل` |
| Volume | «الشمعة قوية… والفوليوم ضعيف.» / «منو يدفع الحركة؟» | `فوليوم` |
| VWAP | «السعر ابتعد عن قيمته.» / «يرجع ولا يكمل؟» | `VWAP` |

CTA format: `اكتب "[الكلمة]" وخذ قائمة الفحص` + a save reason (`احفظ الريل وراجعه قبل تحليلك الجاي`) + a share
reason (`وأرسله لمتداول يعتمد على أداة واحدة`). Keep the keyword unique within a batch.

Note: the shipped stop-placement reel uses the topic-specific keyword `ستوب` (stop placement), which fits its
subject better than the generic `بروفايل`. Choose the keyword that matches the piece's actual takeaway.
