سقط، فأرقامُه تُعاد قياسها على البيانات الجديدة قبل أيِّ استعمال.

  ثم تبيّن أنّ النافذتين اليوميّتين الحرّتين كلتيهما موسومتان `bad`

  إغلاق يومي غير موثوق». والافتتاحاتُ هي مادّةُ الدرس نفسه، فقياسُ
