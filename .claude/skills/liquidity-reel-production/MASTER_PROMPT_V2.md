## التحولات الحاكمة عن V1 والأوامر السابقة
1. **التعليق الصوتي رجع إلزامياً**: عربي فصيح حديث، نبرة هادئة واثقة تعليمية سينمائية، 120–145 كلمة/دقيقة، وقفات 0.2–0.5ث، جمل ≤18 كلمة، عبارات احتمالية بلا وعود. يُسلَّم: سكربت كامل + نسخة موقّتة + نسخة مشكولة جزئياً + تعليمات أداء + نطق المصطلحات. (يلغي «مؤثرات فقط بدون كلام»)
2. **الفصحى إلزامية** بكل الهوكات والنصوص الظاهرة والتعليق الصوتي — **ممنوع العامية والكويتية** بالمحتوى المنشور. المصطلح الإنجليزي بين قوسين بعد العربي: الفجوة السعرية العادلة (FVG)، كسر الهيكل (BOS)، تغير هيكل السوق (MSS)، نقطة التحكم (POC)، VAH/VAL.
3. **نظام الهويتين الصارم**: (أ) داكن فقط في: البوستر المستقل، غلاف الريل، الصفحة الأولى للكاروسيل، أول 1.5–2.5ث من الريل. (ب) **أوف وايت من بعدها حتى النهاية** — بمافيها صفحة CTA. ممنوع الرجوع للداكن أو الخلط.
4. مدة الريل المعيارية 25–40ث (نموذج 35ث × 8 مشاهد).

## نظام الهوكات

## بنية الكاروسيل (8 صفحات — نموذج FVG)
01_Dark_Cover (داكنة: هوك + تعريفية + جارت مصغر + اسحب←) → 02_Definition (التعريف + 3 شموع + تحديد الفجوة) → 03_Formation (شلون تتكون: 1-2-3 المسافة بين ذيل 1 وذيل 3) → 04_Strong_FVG (شروط القوة ببطاقات: بعد كسر هيكل، اندفاع، مع الاتجاه، بعد سحب سيولة + جارت BOS/اندفاع/FVG) → 05_Weak_FVG (متى تتجاهلها + مقارنة قوية/ضعيفة) → 06_Entry_Model (التسلسل السباعي + Entry/Stop/Target/Invalidation) → 07_Common_Mistake (مثال ✗ ومثال ✓) → 08_CTA (أوف وايت: «الفجوة أداة وليست إشارة مستقلة» + الخلاصة الرباعية + CTA واحد). ماستر 2160×2700، تسليم 1080×1350 PNG منفصلة.

## بنية الريل (نموذج 35ث — FVG)
م1 (0–2.5 داكن): لوقو + كلوز أب الفجوة + هوك «لماذا يعود السعر إلى الفجوة؟» + Mask Reveal + Low Impact + VO: «لماذا يعود السعر إلى الفجوة السعرية بعد أن يندفع بعيداً عنها؟» → م2 (2.5–6): **Light Sweep من الداكن للأوف وايت**، 3 شموع + FVG، «اختلال في توازن التداول» → م3 (6–11): كشف الشموع الثلاث + رسم المنطقة بين الذيول → م4 (11–16): سياق كامل BOS/اندفاع/FVG، «ليست كل فجوة قوية» → م5 (16–22): BOS + سحب سيولة + اندفاع + FVG، «الاتجاه، السيولة، ثم الاندفاع» → م6 (22–28): العودة + Entry/Stop/Target، «انتظر العودة والتأكيد» → م7 (28–32): مقارنة عشوائي/مؤكد، «الفجوة ليست إشارة مستقلة» → م8 (32–35 أوف وايت): لوقو + CTA «اكتب فجوة» + خفض موسيقى + Logo Sting.
