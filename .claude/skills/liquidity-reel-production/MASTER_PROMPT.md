## 2. المرجع الأساسي للجارت
الجارت المرفق (صورة/فيديو/OHLC) = مصدر الحقيقة الوحيد. ممنوع تغيير أو اختراع: الاتجاه، عدد/ترتيب/أجسام/ذيول الشموع، القمم والقيعان، مناطق السيولة، توقيت السويب، الدخول/الستوب/الهدف، الفريم، أسعار المحور، شكل Volume Profile، أرقام Footprint، قيم Delta.
- OHLC/CSV → إعادة بناء رياضية بلا إضافة/حذف/تعديل.
- Screenshot فقط → Chart Plate ثابتة + طبقات ماركب مستقلة فوقها، بلا إعادة رسم أو تمديد أو تشويه.
- تسجيل TradingView → التسجيل هو الأساس + زوم/ماركب فوقه بـ Motion Tracking.
- بلا جارت حقيقي → مثال تعليمي موسوم بوضوح «Illustrative Educational Example» ولا يُقدَّم كتحليل حقيقي.

## 3. دقة شموع TradingView
جسم مستطيل نظيف، فتائل رفيعة متصلة بمنتصف الجسم، الجسم = Open/Close والذيول = High/Low بدقة. ممنوع: شموع 3D/كريستالية، ظلال تغيّر القراءة، Glow قوي حول الأجسام، إضافة/حذف/نقل/قلب أي شمعة، تغيير نتيجة الصفقة، كسر مستوى لم يُكسر.
الألوان (ثيم الريلات السينمائي): خلفية كحلية داكنة مائلة للأسود، Bullish تركوازي/Cyan هادئ، Bearish فضي داكن/رمادي بارد، الفتائل أفتح قليلاً من الأجسام، Grid خافتة جداً. الوضوح قبل الإبهار.

## 4. الهوية البصرية
Premium · Institutional · Technical · Minimal · Cinematic · Clean. نص أبيض/فضي وثانوي رمادي فاتح، لمسات Cyan/Teal محدودة، ألوان تحذيرية هادئة للستوب. عناصر مسموحة باعتدال: خطوط HUD رفيعة، Grid هندسية خافتة، دوائر تقنية، Dark Glass Cards، حواف مضيئة رفيعة، Light Sweep خفيف، Film Grain خفيف جداً، Vignette دقيقة، عمق طبقات. ممنوع المبالغة: Neon، Glow، Particles، Lens Flare، Smoke، Glitch، 3D، ضجيج بصري. اللوقو الرسمي فقط: بلا إعادة رسم/تغيير نسب/Glow قوي، موقع ثابت داخل Safe Zone.

## 5. الكاروسيل
1080×1350 (تصميم 2160×2700، sRGB، PNG، كل صفحة ملف): 1 Hook (جملة 4–7 كلمات تبدأ بالمشكلة/النتيجة، نص أقل ما يمكن) → 2 Context (الجارت كامل + منطقة الاهتمام بلا كشف الحل) → 3 Structure (قمة/قاع/هيكل بخطوط دقيقة ومسميات قصيرة) → 4 Liquidity Event (تجمع السيولة والسويب مربوط بالشمعة الصح) → 5 Confirmation (سبب التأكيد بكلوز أب: Absorption/Delta Shift/FVG/MSS/Volume Rejection/Stacked Imbalance) → 6 Execution (Entry/SL/Target/Invalidation + سبب بجملة) → 7 Lesson (قاعدة قابلة للتطبيق بلا تكرار) → 8 CTA (واحد، كلمة التعليق أكبر عنصر). استمرارية: مستند واحد — هوامش/لوقو/ألوان/ماركب/عناوين ثابتة، كل صفحة تضيف معلومة.
تسمية الملفات: 01_Cover، 02_Context، 03_Structure، 04_Liquidity، 05_Confirmation، 06_Execution، 07_Lesson، 08_CTA.

## 6–7. الريل وبنيته الزمنية (نموذج 30ث)
1080×1920 (ماستر 2160×3840)، 30/60fps، Safe Zones، النص خارج واجهة Instagram.
0–2 Pattern Interrupt (هوك فوري + Sound Hit منخفض قوي) → 2–6 Establishing (زوم أوت كاشف + الأصل/الفريم + بارالاكس خفيف + سؤال) → 6–11 Setup (القاع/القمة + Liquidity Line + كاميرا نحو الحدث) → 11–16 Liquidity Event (زوم إن تدريجي + شمعة السويب + Freeze قصير + عنصر ماركب واحد + Impact خفيف) → 16–22 Confirmation (الدليل مع النص بالتزامن مع الماركب) → 22–27 Execution (Entry/Invalidation/Target بخطوط نظيفة + ذروة الموسيقى) → 27–30 Lesson+CTA (تهدئة + قاعدة + CTA واحد + لوقو).

## 8. تحريك الجارت
ثلاثة أنظمة: (1) تسجيل TradingView حقيقي: التسجيل نفسه + Speed Ramp محدود + Freeze عند الحدث + ماركب Motion Tracking. (2) OHLC Reconstruction: بناء الشموع من البيانات بالترتيب، كل شمعة حسب بياناتها، **بلا Bounce وبلا Overshoot وبلا أنيميشن موحد لكل الشموع**. (3) Static Chart Animation: الصورة الأصلية + كاميرا/Masks فوقها بلا تحريك شمعة منفردة.
قواعد عامة: لا شموع تطفو/تبتعد عن المحور، لا Shake مستمر، لا Glitch على الأسعار، لا تغيير نسب أثناء الزوم، السرعة لا تسبق الفهم.

## 9. الكاميرا
هادئة ومقصودة. Zoom In فقط عند الحدث (سويب/دخول/Footprint/امتصاص/دلتا/POC/ستوب) — النطاق السياقي 102–112%، والأكبر منه في **Detail Shot** مستقل فقط. Zoom Out للسياق والكشف. Pan يتبع اتجاه القراءة بـ Ease In/Out ومركزه نقطة الاهتمام. Freeze Frame قصير عند: السويب، كسر الهيكل، الامتصاص، الدخول، شمعة التأكيد (أثناءه: خلفية أهدأ + ماركب + نص + مؤثر دقيق). Shake مرة واحدة قصيرة منخفضة. Motion Blur خفيف لا يطمس شموعاً/نصاً/أرقاماً.

## 10–11. Parallax والخلفية
طبقات: Background Gradient → Technical Grid → Chart Plate → Markup → Text → Logo → Foreground Light. الخلفية أبطأ، الماركب ملتصق بالجارت، بلا بارالاكس يفصل الجارت عن بياناته. الخلفية حية غير مشتتة: Gradient Motion بطيء، Cyan هادئ، Grid Pulse محدود، Light Sweep خفيف، Vignette، Film Grain، DoF بسيط. ممنوع: دخان/نيران/برق/انفجارات/Neon صارخ/حركة سريعة مستمرة.

## 12. النصوص
كل لقطة فكرة واحدة، 3–8 كلمات، سطران كحد أغلب، عربية سليمة RTL بحروف متصلة، خليجي خفيف تعليمي قوي، بلا وعود أرباح. أنيميشن: Fade Up، Mask Reveal، Tracking Reveal، Word-by-Word، Subtle Scale، Line Wipe. ممنوع: Bounce/دوران/تكسير/Glitch/اهتزاز/كرتوني. إبراز كلمة أو كلمتين بـ Cyan/Teal فقط، لونان كحد أقصى.

## 13. الماركب
مطابق TradingView: خطوط/رايات/ترند/زونات/Entry/SL/TP/سهم/قوس/دائرة تركيز/Footprint Highlight/VP Range/POC/VAH/VAL/Delta Label/تعليق قصير. القواعد: مربوط بالقمة/القاع الصح بمراسي دقيقة، السهم لا يغطي جسم/ذيل الشمعة، المسميات خارج حركة السعر، سماكة موحدة، ≤3 أنماط خطوط، كشف تدريجي عند الحاجة وإزالة العنصر بانتهاء دوره، Motion Tracking مع الزوم والبان. الألوان: سيولة Cyan خافت، دخول أبيض/تركواز، ستوب تحذيري هادئ، هدف تركواز فاتح/فضي، Invalidation متقطع، ثانوي رمادي شفاف — ولا اعتماد على اللون وحده (Labels + أنماط + رموز).

## 14–15. دقة Footprint وVolume Profile
Footprint: ‏Bid×Ask حقيقية، لا دلتا مخترعة، لا «Absorption» بلا دليل (حجم تنفيذ + فشل استمرار + سلوك الشمعة)، أرقام حادة مقروءة بكلوز أب بلا تشويه. VP: البروفايل على النطاق الصحيح بتوزيعه الحقيقي، POC/VAH/VAL مطابقة، لون واحد بدرجات شفافية، ليس زخرفة.

## 16–18. الصوت
موسيقى أصلية/مرخصة: Cinematic Electronic · Minimal Hybrid · Dark Financial Thriller · توتر منخفض التردد. البناء: بداية هادئة غامضة → تصاعد بالإعداد → Impact+Music Dip عند السويب → عودة أوضح بالتأكيد → تهدئة عند CTA + Logo Sting. المؤثرات (محدودة مربوطة بالحدث): Click عند المستوى، Whoosh عند الزوم، Impact عند السويب، Pulse عند Footprint، Marker Draw عند الرسم، Reverse Sweep قبل التأكيد، Sub Drop عند الفشل، Logo Sting بالنهاية. ممنوع: صوت مع كل حركة، انفجارات، كرتوني، تكرار ممل. المكس: الموسيقى واضحة غير صاخبة، المؤثرات أعلى بلحظات الحدث بلا Clipping، مساحات صمت قصيرة، مناسب لسماعات الهاتف. الهدف: ‏Integrated ≈ −14 LUFS، ‏True Peak < −1 dBTP.

## 22. خطة ما قبل التنفيذ (إلزامية قبل أي إنتاج)
