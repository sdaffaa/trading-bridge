## قابلية إعادة الإنتاج
- `data/gld_daily.csv` — البيانات الخام (100 يوم).
- `analyze.js` — يتحقق من OHLC، يبني البروفايل، ويفحص شرط «اختراق VAH → فشل → عودة إلى POC ثم VAL» حسابيًا، ويكتب `data/scenario.json`.
- `scene.js` + `gen.js` + `render.js` — محرّك الإطارات (Playwright → 705 إطار) ثم ffmpeg.
أعد التشغيل: `node analyze.js && node gen.js && node render.js`.
