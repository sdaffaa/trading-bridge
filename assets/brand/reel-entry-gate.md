## ١ · الشروط الثمانية

الترتيب هو ترتيب **إمكانية الفحص**: ما تقدر تعرف البلوك قبل الكسر، ولا تعرف الـ R
قبل البلوك.

| # | الشرط | يُفحص بـ | النتيجة على هذا الجارت |
|---|---|---|---|
| ١ | اتجاه صاعد | قمة أعلى **و**قاع أعلى | 104.00 > 100.50 ✓ |
| ٢ | كسر بإغلاق | إغلاق فوق القمة، مو مجرد ظل | الشمعة 32 ✓ |
| ٣ | اندفاع أكبر من المعتاد | جسم شمعة الكسر ÷ معدل آخر ١٠ أجسام ≥ 1.5 | **1.72×** ✓ |
| ٤ | آخر شمعة هابطة | الشمعة ٢٨ هابطة، و٢٩ و٣٠ و٣١ كلهن صاعدات | الشمعة 28 ✓ |
| ٥ | الرجوع بعد الكسر | شمعة الدخول بعد شمعة الكسر | 39 > 32 ✓ |
| ٦ | رفض فوق البلوك | تلمس قمة البلوك و**تغلق فوقها** | 101.80 > 100.90 ✓ |
| ٧ | الخطر ≤ ٤٠٪ من الساق | (قمة البلوك − قاعه) ÷ (الهدف − قاع البلوك) | **30%** ✓ |
| ٨ | العائد ٢R على الأقل | (الهدف − الدخول) ÷ الخطر ≥ 2 | **2.35R** ✓ |

**الأربعة الأخيرة هي الفرق.** ١–٤ يشوفها أي أحد على الجارت. ٥ يمنع الدخول من بلوك
قبل ما يتأكد الكسر. ٦ يمنع الدخول على بلوك السعر عدّاه بدل ما ارتد منه. ٧ يمنع
صفقة بلوكها كبير مقارنة بالحركة اللي ينتظرها. ٨ يمنع صفقة صحيحة الشكل وعائدها لا
يستاهل.

> **كل شرط مفحوص بالكود على الشموع، مو مكتوب بكابشن.** لو واحد منهم كان خطأ، مربّعه
> ما راح يضيء، وما راح يقول العكس. والرقم اللي جنب كل شرط هو الرقم اللي عدّى فيه —
> بحيث اللي يوقف الفيديو يقدر يتحقق بدل ما يصدّق.

## ٣ · الصفقة

```js
const BOS   = C[20].h;                 // 104.00
const OB_T  = C[28].h, OB_B = C[28].l; // 100.90 / 98.90
const ENTRY = OB_T, STOP = OB_B, TGT = C[32].h;   // 100.90 / 98.90 / 105.60
const RISK  = ENTRY - STOP;            // 2.00
const LEG   = TGT - OB_B;              // 6.70   الساق اللي أنتجها البلوك
const R     = (TGT - ENTRY) / RISK;    // 2.35
```

| | |
|---|---|
| الدخول · الستوب · الهدف | **100.90** · **98.90** · **105.60** |
| الخطر | **2.00** = ارتفاع البلوك نفسه |
| النتيجة | **+2.35R** — ما تظهر إلا بعد وصول الهدف |
| الدخول أول ما يُلمس | الشمعة ٣٩ |
| الهدف أول ما يوصل | الشمعة ٤٨ |
| الستوب | **ما انلمس** — أدنى قاع بعد الدخول 101.40 |
| مخالفات الرسم | **صفر** |
