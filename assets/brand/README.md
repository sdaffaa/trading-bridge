# Liquidity State — Brand Identity Assets

Canonical logo files for **@liquidity.state**. This is the saved brand identity logo.

## Logo files

| File | Use |
|---|---|
| `logo/liquidity-state-logo-light.svg` / `.png` | Primary lockup on light / cream backgrounds (matches the reference artwork) |
| `logo/liquidity-state-logo-dark.svg` / `.png` | Primary lockup on the brand's dark-teal background (default for posts/reels) |
| `logo/liquidity-state-mark.svg` / `.png` | Gem mark only, transparent — watermark, profile icon, favicon |

SVGs are the source of truth (vector, infinitely scalable, editable colors). PNGs are exported at 2400 px wide (mark at 1200 px) for direct use.

## The mark

A faceted silver / steel gem (icosahedron / crystal) — the metallic accent of the brand.
Keep it small and never dominating: bottom-center or bottom-corner watermark on posts and reels.

## Wordmark

`LIQUIDITY STATE` — elegant serif, wide letter-spacing (tracking ≈ 20), with a thin divider and a
center diamond beneath. Set in deep navy `#2B3D4F` on light, white `#FFFFFF` on dark.
Font stack: Cormorant Garamond / Trajan Pro / Times New Roman (serif). Swap in the licensed brand
display face when producing final assets.

Full brand system: see the `liquidity-state-brand` skill (colors, typography, voice, content rules).

## Notes

- The SVGs here are a faithful vector recreation of the supplied reference logo, built to the brand
  palette. If you have the original raster/vector master file, drop it into `logo/` alongside these
  (e.g. `logo/liquidity-state-logo-original.png`) to keep it as the archival source.
- Clear space: keep at least the height of the gem clear on all sides. Minimum mark size: 40 px.
- Do not recolor the gem, stretch the lockup, or place the light lockup on busy/low-contrast photos.
