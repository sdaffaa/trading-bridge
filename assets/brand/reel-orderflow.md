# المدرسة الرابعة — ورقة التسجيل
### `reel-orderflow.html` → `reel-orderflow.mp4` · 1080×1920 · 33.00s · 30fps

الجزء السابع، وهو **جواب السؤال الذي أقفل به الجزء السادس**: «والمدرسة الرابعة؟».
الجارت يحمل ثلاث مدارس ولا يحمل الرابعة، فتجيء الرابعة في **بطاقة سُلّم فوت برنت**
تحت الجارت.

**التصميم:** نفس منهج آخر ثلاثة ريلز — الهوية الكريمية، مكوّنات `.ls-vr`، الجارت
داخل بطاقة بإطار، وساعة واحدة تقود كل شيء. الجديد هنا **بطاقة السلّم** و**صفّ
مربّعات المدارس الأربع**.

**الجارت جديد بالكامل** (بذرة `771103`، رينج ٣٢ شمعة) ولا يشترك بشمعة واحدة مع
الجزء السادس.

## ٢ · الفوت برنت: ما هو صادق فيه، وما هو موضوع

الدلتا واختلال التوازن **لا يُشتقّان من OHLC**، وهذا الجارت ما فيه بيانات تِك.
فالصفوف **توضيحية، ومكتوب على الشاشة أنها توضيحية**:

> «أرقام التدفّق توضيحية — الجارت لا يحمل بيانات تِك»

لكن **الحساب ليس توضيحياً**:

| | |
|---|---|
| الدلتا | مجموع الـ Ask − مجموع الـ Bid = 3640 − 1830 = **+1810** |
| الصف المضيء | أثقل صف بالمجموع فعلاً (410 + 980) — يُحسب لا يُختار |
| الاختلال | 980 ÷ 410 = **2.39** |
| موضع الصف الأثقل | **هو سعر الدخول نفسه** — وهذا شرط المدرسة الرابعة |

الرسم التعليمي يبقى ملزماً بأن يجمع صح. والسُلّم **دائماً LTR**: الـ Bid يسار
والـ Ask يمين (`assets/brand/footprint.js`).
