# صيغة الريل العمودي
### 1080×1920 · مكوّنات `.ls-vr` · القالب المرجعي: `reel-confluence.html`

هذه طريقة التصميم المعتمدة للريلز. مُستخلصة من `reel-orderblock` و
`reel-entry-gate` و`reel-confluence` — والأخير هو المرجع الأكمل.

المبدأ الحاكم: **ساعة واحدة، وكل شيء على الشاشة يثبت نفسه.**

## ٢ · ساعة واحدة

`seek(t)` واحدة تقود الجارت والكابشن والطبقات فوقها. لا مؤقّتات منفصلة، ولا
`setTimeout` — لأن أي ساعة ثانية تنزاح، والانزياح لا يُلاحظ إلا بعد التصيير.

```js
function seekAll(t) {
  ch.seek(ct); caps.seek(t);   // الجارت والكابشن
  /* والباقي: البطاقات، الحجاب، الأرقام — كلها دوال في t */
}
```

### الوقفات

الشموع تُطبع بمعدل ثابت، والوقفات هي مكان رواية القصة. **كل وقفة توضع على البيت
الذي تنزل كلماته فوقها**، فتصل الصورة والجملة معاً.

> **`atBar` هي الشمعة التي تتوقف الإعادة قبلها.** الوقوف لرؤية الشمعة N يُكتب
> `atBar: N+1`. بدون هذا كل وقفة تحطّ على الشمعة السابقة للتي تتكلم عنها — وهو
> خطأ صامت لا يظهر إلا بمقارنة الإطارات.

```js
const HOLDS = [{ atBar: 35, seconds: 4.0 }, …];
ch.replay({ rate: 3.9, window: 56, start: 18, at: 0, holds: HOLDS });
const H = Object.fromEntries(HOLDS.map(h => [h.atBar, h.t]));   // ← جدولة الماركب
```

**بلا انزلاق للجارت** حين يكون على الشاشة عنصر مربوط ببداية السلسلة (هستوغرام
الفوليوم بروفايل مثلاً): اجعل `barsVisible` = عدد الشموع كله.

## ٣ · البطاقات تثبت نفسها

المربّع أو البطاقة **موجود من الإطار صفر مطفياً**، ويضيء لحظة ما **يثبته الجارت
فعلاً** — لا حسب جدول زمني منفصل:

```js
const COND = [{ ok: C[bosBar].c > BOS, note: `bar ${bosBar}` }, …];
el.classList.toggle('on', past(COND_AT[i]) && COND[i].ok);
```

- **الشرط الذي لا يتحقق يبقى مطفياً** ولا يقول العكس.
- **ومطفي ≠ مرفوض.** الباهت معناه «ما انفحص بعد». إذا فُحص وسقط فله حالة ثالثة
  `.no`: الأحمر `--ls-invalid` و`✗` و**الرقم الذي سقط عليه**. المرجع:
  `reel-no-trade.html`. خلط الحالتين في لون واحد يخفي أهمّ نتيجة يملكها الحساب.
- **كل بطاقة تحمل الرقم الذي عدّت به** (`2.95×`، `32%`، `bar 34`) — بحيث من يوقف
  الفيديو يتحقق بدل أن يصدّق.
- **بطاقة المدرسة تضيء كاملة أو لا تضيء**: الشرطان معاً. مدرسة بشرط واحد ليست
  متفقة.
- **ترتيب الإضاءة هو ترتيب إمكانية الفحص**، لا ترتيب الجمال: القيمة تُقاس قبل
  الحركة، والـ R لا يُعرف قبل أن يُعرف البلوك.

المربّعات الموجودة من البداية مطفية **شريط تقدّم** بقدر ما هي مفتاح: المشاهد يرى
كم بقي، وهذا سبب يبقيه.

## ٣ب · حافة القيمة تُقرَّب قبل أن يُبنى عليها

حافة منطقة القيمة **حدّ صندوق حسابي، لا سعر طبعه السوق**. إذا تُركت بعشراتها
الكاملة صار قول «قاع الفجوة والـ VAH نفس السعر» صحيحاً لخانتين فقط: الشمعة تحمل
`101.82` والمستوى يحمل `101.8237`.

```js
const r2  = v => Math.round(v * 100) / 100;
const VAH = r2(pc.profile.vah);      // ← قبل أي شمعة تُكتب
const V   = d => r2(VAH + d);
```

فتصير الثلاثة **رقماً واحداً حرفياً**. وبدون هذا قد يفشل بحث `findIndex` عن شمعة
الدخول أصلاً — لأن `high` المدوَّرة تنقص عن الحافة غير المدوَّرة بجزء من ألف.

## ٤ · النتيجة محجوبة

`النتيجة` تبقى `—` حتى يصل السعر للهدف فعلاً. إظهار `+2.13R` بجانب الدخول يحرق
الشيء الوحيد الذي ينتظره المشاهد، **ويعلن نتيجة لم ينتجها الجارت بعد**.

---

## ٥ · الحكم والحجاب

الحكم (البيت ٨) ينزل حين يكون الجارت في أشد ازدحامه، وعنوانٌ فوق شمعة طويلة لا
يُقرأ. فيتراجع الجارت خلف **حجاب من خلفية الصفحة نفسها** (`.ls-vr-scrim`) بدل أن
يتصارع النص معه — ولأن الحجاب من التوكنات، يعمل بالهويتين بلا قاعدة ثانية.

**ولا يُحجب قبل أن تهبط الذروة**: إن كان وصول الهدف هو العائد، فالحجاب بعده لا
فوقه.

## ٦ · خياطة اللوب

آخر 1.2 ثانية **تُرجِع الإعادة للخلف** بدل أن تقطع:

```js
if (t > SEAM) ct = CHART_END * (1 - ease(seg(t, SEAM, TOTAL - SEAM)));
```

فيصير الإطار الأخير **هو الإطار صفر حرفياً**. وهذا **يُقاس** بفرق البكسل بين
الاثنين ولا يُدّعى — القيمة المطلوبة `0.0`. و`window.LS_TAIL = 0` يمنع سكربت
التصيير من إضافة ذيل بعد الخياطة.

## ٧ · السكربت والمدة

الـ١١ بيتاً من `fahad-script-voice`، واسم مرساة واحد لكل ريل (الشمعة · الصفقة ·
الستوب · الاتجاه · الشرط · المدرسة — واحد لكل جزء، لا يتكرر).

المدة من `skip-rate-under-30`. الصفقة الموثقة ٢٥–٣٥ ثانية. **يُذكر نطاق التخطي
المتوقع بصدق.** وإذا ساءت النتيجة، العلاج **تحويل المحتوى لكاروسيل** لا قصّ
الشروط — الشروط هي القيمة.

## ٨ · البناء والتحقّق

```bash
python3 capture-motion.py reel-confluence.html reel-confluence.mp4 30
```

الصفحة تعلن عن نفسها:

```js
window.LS_SIZE = [1080, 1920];
window.LS_DURATION = TOTAL;
window.LS_TAIL = 0;                 // آخر إطار هو الخياطة — لا ذيل بعده
window.LS_VIOLATIONS = ch.violations;
window.seekTo = t => { seekAll(t); return true; };
document.fonts.ready.then(() => { seekAll(0); window.LS_READY = true; });
```

`LS_READY` **بعد** `document.fonts.ready`: التخطيط يقيس عرض النص ليقصّ الخط حول
الملصق، والقياس قبل وصول الخط يعطي عرضاً خاطئاً. وسكربت التصيير **يرفض** أن يصرف
دقيقتين على صفحة كسر رسمُها قاعدته.

**قائمة التحقّق قبل التسليم:**

- [ ] مخالفات الرسم **صفر**
- [ ] كل شرط `ok === true`، وكل رقم على الشاشة مقروء من الشموع
- [ ] الصفقة متحقّقة **مستقلاً**: متى لُمس الدخول، هل لُمس الستوب، متى وصل الهدف
- [ ] خياطة اللوب مقيسة = `0.0`
- [ ] أطول فترة بلا تغيّر بصري **< ١٫٥ ثانية**
- [ ] الكاروسيل يُعاد تصييره **مطابقاً بالبكسل** بعد أي تغيير بالمحرّك
- [ ] ٣–٤ مدارس متفقة على نفس السعر (`CLAUDE.md` §١)
- [ ] **الجارت جديد** — بذرة وهيكل لا يشبهان أي ريل سابق (`CLAUDE.md` §٣)
- [ ] «مثال تخطيطي لغرض تعليمي — ليست توصية» على الشاشة
