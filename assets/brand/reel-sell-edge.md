الجزء التاسع. البوابة نفسها، **بالاتجاه المعاكس** — وكل شرط يحمل الكلمة التي
حلّ محلّها في جهة الشراء.

**التصميم:** نفس منهج الأجزاء ٦–٨. الإضافة الوحيدة عنصر `<i>` داخل الشرط:
الكلمة القديمة **مشطوبة** بجانب الجديدة، فيصير القلب مقروءاً بلا شرح.

**الجارت جديد** (بذرة `9174253`، رينج ٣٠ شمعة، والكسر **هابط**) — الشكل نفسه
مختلف عن كل ما سبق، لا البذرة وحدها.

## ١ · ما ينقلب

| الشراء | البيع |
|---|---|
| BOS صاعد بإغلاق | **BOS هابط بإغلاق** |
| Order Block هابط | **Order Block صاعد** |
| FVG صاعدة | **FVG هابطة** |
| قبول فوق الـ VAH | **قبول تحت الـ VAL** |
| الـ VAH صار دعماً | **الـ VAL صار مقاومة** |
| الستوب تحت البلوك | **الستوب فوق البلوك** |
| **قاع** الفجوة = الدخول | **سقف** الفجوة = الدخول |

**وما لا ينقلب:** حساب المخاطرة. الخطر ≤ ٤٠٪ من الساق، والعائد ≥ ٢R — نفس
الرقمين بالاتجاهين.
