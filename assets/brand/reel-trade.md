## ٣ · الصفقة — كل رقم مقروء من الشموع

**لا سعر واحد مكتوب باليد في أي ملصق.** الكود يقرأها من الشموع، و R حساب على ثلاثة
منها:

```js
const BSL   = C[20].h;              // 100.00  السيولة الشرائية
const MSS   = C[27].l;              //  95.80  آخر قاع بنّاء
const FVG_B = C[32].h, FVG_T = C[30].l;   // 95.20 – 97.50  الفجوة
const ENTRY = FVG_T;                //  97.50  حافة الفجوة = قاع شمعة السحب
const STOP  = C[30].h;              // 101.80  فوق ظل السحب
const TGT   = C[12].l;              //  89.20  السيولة البيعية تحت
const R     = (ENTRY - TGT) / (STOP - ENTRY);   // = 1.9302…  →  +1.93R
```

| ما تحقّق منه | النتيجة |
|---|---|
| كل مستوى على طرف ظل حقيقي | ✓ (BSL / MSS / ENTRY / TGT) |
| الفجوة فجوة فعلاً (قمة الشمعة ٣٢ < قاع الشمعة ٣٠) | ✓ |
| أول شمعة تلمس الدخول | ٣٥ |
| الستوب لم يُلمس بين الدخول والهدف | ✓ نجا بفارق **4.30** |
| أول شمعة تصل الهدف | ٤٤ |
| مخالفات الرسم | **صفر** |

**نتيجة الصفقة `+1.93R` لا تظهر على البطاقة إلا بعد وصول الهدف فعلاً.** طباعتها
بجانب الدخول تحرق الشي الوحيد اللي ينتظره المشاهد، وتعلن نتيجة ما أنتجها الجارت بعد.

## ٤ · الخطوات الخمس على الشاشة

شريط الخطوات موجود من الإطار صفر، مطفياً. كل خطوة تضيء لحظة حدوثها فعلاً — وهو
شريط تقدّم بقدر ما هو مفتاح: المشاهد يشوف چم خطوة باقية، وهذا سبب يخليه يكمل.

| # | الخطوة | الوقفة | ما يُرسم |
|---|---|---|---|
| ١ | **سحب** | 6.91 | مستوى `سيولة شرائية` ينتهي عند الشمعة ٣٠ — الخط يخلص لأن السيولة انسحبت |
| ٢ | **كسر** | 9.83 | مستوى `آخر قاع` بـ `mode:'close'` ينتهي عند الشمعة ٣١ |
| ٣ | **فجوة** | 12.54 | صندوق `whole:false` ينتهي عند الشمعة ٣٥ — أول شمعة ترجع فيه |
| ٤ | **دخول** | 15.68 | `position()` — كتلة الخطر فوق وكتلة الهدف تحت، والنسبة بينهما مرئية |
| ٥ | **هدف** | 22.09 | مستوى `سيولة بيعية` ينتهي عند الشمعة ٤٤، وتُكشف النتيجة |

كل وقفة نهايتها هي نهاية رسم — أي أن **قاعدة الدقة نفسها هي اللي تروي القصة**:
الخط ينتهي عند الشمعة اللي أنهته، فنهايته حدث لا تنسيق.

`atBar` في الوقفة هي الشمعة اللي تتوقف **قبلها**، فوقفة تنظر للشمعة N تُكتب `N+1`.
