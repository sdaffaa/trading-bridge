## ٣ · الصفقة — كل رقم مقروء من الشموع

```js
const BOS   = C[20].h;                 // 104.00  قمة الهيكل
const OB_T  = C[28].h, OB_B = C[28].l; // 100.90 / 98.90  الأوردر بلوك كاملاً
const ENTRY = OB_T;                    // 100.90  قمة البلوك
const STOP  = OB_B;                    //  98.90  قاع البلوك
const TGT   = C[33].h;                 // 105.20  قمة الاندفاع
const R     = (TGT - ENTRY) / (ENTRY - STOP);   // = 2.15
```

| ما تحقّق منه | النتيجة |
|---|---|
| اتجاه صاعد فعلاً — قمة أعلى وقاع أعلى | ✓ |
| الشمعة ٣١ **تلمس** 104.00 ولا **تغلق** فوقها | ✓ اللمس مو كسر |
| أول إغلاق فوق الهيكل | الشمعة ٣٢ |
| البلوك هو فعلاً آخر شمعة هابطة قبل الاندفاع | ✓ (٢٩ و٣٠ و٣١ كلها صاعدة) |
| الدخول والستوب على أطراف ظل حقيقية | ✓ قمة وقاع الشمعة ٢٨ |
| أول شمعة ترجع للبلوك | ٣٩ |
| الستوب ما انلمس بعد الدخول | ✓ نجا بفارق **2.50** |
| أول شمعة توصل الهدف | ٤٨ |
| مخالفات الرسم | **صفر** |

الخطر **2.00** والنتيجة **+2.15R**، ولا تظهر إلا بعد وصول الهدف فعلاً.

> **صندوق الأوردر بلوك يلفّ الشمعة كاملة، ظل لظل.** لو اقتُصّ على الجسم لاختفى
> القاع اللي يُقاس منه الستوب — وهذا بالضبط سبب القاعدة.
